# Shop Management System

A Windows Forms shop management application built with .NET 8 and SQL Server.

## Requirements

- Visual Studio 2022
- .NET 8 Windows Desktop workload
- SQL Server Express

## Run

1. Open `ShopManagementSystem.sln` in Visual Studio.
2. Update the SQL Server connection in `ShopManagementSystem/DBConnection.cs` for your local database.
3. Build and run the project.
